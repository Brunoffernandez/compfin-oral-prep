\hypertarget{the-task-in-my-own-words}{%
\section{The task (in my own words)}\label{the-task-in-my-own-words}}

\textbf{Exercise 1 --- Implied volatility.} From a CSV of SPX call/put
quotes (expiry 2021-12-01, near-the-money), back out the Black--Scholes
implied volatility for each call strike by solving
\texttt{C\_BS(S0,K,r,T,σ)\ =\ C\_mkt} two ways: (i) bisection, (ii)
Newton--Raphson. Plot IV vs strike for each, overlay them, and compare
against the CSV's own IV column; discuss why they differ (bid--ask,
dividends, rounding, tolerance). Assumptions fixed by the brief:
\(r = 0.11%
\), Act/365, no dividends.

\textbf{Exercise 4 --- Monte Carlo basket call.} Price a European basket
call with payoff \((A_T − K)^+\), \(A_T = ½(S1(T)+S2(T))\), on two
correlated GBM stocks. Do it two ways: under the risk-neutral measure Q,
and under the QS1 measure (S1 as numéraire) whose dynamics were derived
analytically in Ex. 3. For a grid of path counts
\(M ∈ {10k,25k,50k,75k,100k}\), report price and standard error under
both measures, check the SE decays like \texttt{1/√M}, and explain the
variance reduction of QS1. Run it for two parameter scenarios.

\hypertarget{exercise-1-exercise_1_computational_finance-2.py}{%
\subsection{\texorpdfstring{Exercise 1 ---
\texttt{exercise\_1\_computational\_finance\ (2).py}}{Exercise 1 --- exercise\_1\_computational\_finance (2).py}}\label{exercise-1-exercise_1_computational_finance-2.py}}

\begin{itemize}
\tightlist
\item
  \textbf{\(C_bs(S0,K,r,T,sigma)\) (lines 9--17).} Black--Scholes call
  price. Line 13--14 guard: if \(sigma<=0\) or \(T<=0\) it returns the
  intrinsic value \(max(S0 − K e^{−rT}, 0)\) instead of dividing by
  zero. Lines 15--17 compute \(d1\), \(d2\) and return
  \(S0·Φ(d1) − K e^{−rT}·Φ(d2)\).
\item
  \textbf{\texttt{implied\_volatility\_bisection(...)} (lines 19--41).}
  Bracketing root-finder for \texttt{C\_bs(σ)\ −\ C\_mkt\ =\ 0}. Lines
  24--25 evaluate the residual at the bracket ends; line 28--29 return
  \(NaN\) if the root is not bracketed
  (\texttt{f\_low·f\_high\ \textgreater{}\ 0}). Lines 30--40 are the
  bisection loop: midpoint at line 31, stop test at line 34
  (\(|f_mid| < tol\) \textbf{or} interval width \(< tol\)), and the
  sub-interval update at lines 37--40. Line 41 returns the midpoint if
  \(max_iter\) is exhausted.
\item
  \textbf{\(Vega(S0,K,r,T,sigma)\) (lines 43--49).} Returns
  \(S0·√T·φ(d1)\), the BS vega, used as the Newton derivative.
\item
  \textbf{\texttt{implied\_volatility\_Newton\_Ralphson(...)} (lines
  51--67).} Newton on the same residual. Line 58 sets the initial guess
  \texttt{σ0\ =\ √((1/T)·2\textbar{}ln(S0/K)\ +\ rT\textbar{})}. Lines
  60--66 iterate \texttt{σ\ ←\ σ\ −\ (C\_bs\ −\ C\_mkt)/vega}, stopping
  when \(|diff| < tol\) (line 64).
\item
  \textbf{Data pipeline (lines 70--96).} Line 70 reads the CSV; line 74
  pulls \(S0\) from the \('SPX'\) row / \('2021-Nov-19'\) column; line
  75 sets \texttt{T\ =\ 12/365}; line 76 sets \(r = 0.0011\). Line 79
  keeps calls only. Lines 82--84 strip commas from \(Strike\) and \(%
  \) from \(IV\) and cast to float, dropping rows with missing
  \(Strike\)/\(Midpoint\). Lines 94--96 build the two IV lists by
  looping over \((Strike, Midpoint)\) pairs, using \(Midpoint\) as
  \(C_mkt\).
\item
  \textbf{Plots (lines 102--127).} Three figures: bisection alone,
  bisection vs Newton, and both vs the CSV \(IV\) column.
\end{itemize}

\section{Results and what they mean}\label{results-and-what-they-mean}}

Reported in the PDF (Figures 4--7), reproduced here as facts the code
produces:

\begin{itemize}
\tightlist
\item
  \textbf{Scenario 1.} Both estimators converge to ≈ 17.18 (Q) / 17.19
  (QS1). SE under Q falls 0.232 → 0.073 as \(M: 10k → 100k\); under QS1
  0.163 → 0.051. Both ratios ≈ \texttt{0.313\ ≈\ 1/√10}, consistent with

  \textbf{Scenario 2.} Both estimators converge to ≈ 32.55 (Q) / 32.56
  (QS1). SE under Q 0.305 → 0.097; under QS1 0.253 → 0.080; ratios ≈
  \texttt{1/√10}. QS1 still lower but the gap is smaller than in
  Scenario 1.
\item
  \textbf{Effective vol explanation in the report.} Scenario 1:
  \( = √(0.04+0.04−2·0.9999·0.04) ≈ 0\), so \texttt{X\_T\ =\ S2/S1} is
  nearly constant under QS1 and the payoff \texttt{(A\_T−K)\^{}+/S1} has
  tiny variance. Scenario 2:
  \( = √(0.01+0.04−2·0.2·0.1·0.2) ≈ √0.042 ≈ 20.5%
  \), so the ratio keeps real volatility and the variance reduction is
  modest.
\end{itemize}
